## How this repo works

Each challenge is a single file in `challenges/<difficulty>/`, containing the question, a
`Your Code Here` section, and the test cases. A challenge counts as **solved** when its file has no
TypeScript errors.

```sh
npm install              # once: installs TypeScript and enables the pre-commit hook
npm run check            # type-check everything and refresh the progress table above
npm run check -- 4 pick  # also show the errors for specific challenges (by number or name)
npm run sync             # pull in challenges added upstream (never overwrites your files)
```

1. Open a challenge, e.g. `challenges/1-easy/00004-pick.ts`.
2. Replace the `any` in `Your Code Here` until the red squiggles in the test cases disappear.
3. Commit. The pre-commit hook re-runs the check and updates the progress table automatically.
